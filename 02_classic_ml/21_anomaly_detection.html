2.21 Anomaly Detection

Поиск аномалий — это не просто классификация с редкими позитивами. Часто меток мало, поведение меняется, цена ошибок несимметрична, а бизнес-порог важнее «сырого» score модели.

Почему важно

Anomaly detection — это ML без меток для большинства случаев. Fraud, intrusion detection, оборудование — задачи, где «нормальное» поведение известно, а аномальное — нет.

Что узнаешь
  • Isolation Forest — как случайные деревья изолируют выбросы
  • One-class SVM — граница нормальности в пространстве признаков
  • Autoencoders для anomaly detection — высокий reconstruction error = аномалия
  • Метрики оценки: когда нет меток и когда они есть
Нужно знать
  • Деревья решений (2.10)
  • SVM (2.13)
  • Нейронные сети (3.1–3.3)

TL;DR

Детектор аномалий учит score «насколько объект необычен», а затем превращает его в действие через порог. Сложные части — определить «норму», справиться с drift, выбрать порог и оценить качество при редких или запаздывающих метках.

Зачем это нужно

Поиск аномалий встречается в антифроде, мониторинге, кибербезопасности, контроле дефектов на производстве, медицинском скрининге, алертах о качестве данных и мониторинге моделей. Везде false positives тратят внимание людей, а false negatives могут дорого стоить.

Используй поиск аномалий, когда
  • Позитивных меток мало или они приходят с задержкой.
  • В основном известно, как выглядит норма.
  • Нужно ранжирование или алерты, а не прямая классификация.
  • Тип аномалий может меняться со временем.
Будь осторожен, когда
  • Нормальное поведение сильно мультимодально.
  • Выбросы в обучающих данных — на самом деле валидные редкие подгруппы.
  • Цена ошибок при выборе порога не определена.
  • Распределение данных дрейфует каждую неделю.

Anomaly score и порог

is_anomaly(x) = 1 if score(x) >= tau else 0
What the symbols mean
xobjectTransaction, sensor reading, user session, image, log event, or data row.
score(x)anomaly scoreHigher means more unusual according to the model or rule.
tauthresholdBusiness decision boundary between normal and alert/action.
1/0decision1 means raise anomaly flag; 0 means treat as normal.
Intuition: the model ranks suspiciousness; the threshold turns ranking into an action.
Analogy: a smoke detector has a sensitivity knob; the same smoke score can trigger or not trigger depending on threshold.

Порог выбирают по цене ошибок, пропускной способности команды или целевой доле алертов. Например, антифрод-команда может разбирать только top 0.5% самых рискованных транзакций.

Isolation Forest

Isolation Forest изолирует аномалии случайными разбиениями по признакам. Необычные точки обычно отделяются за меньшее число разбиений, потому что лежат в разреженных областях.

score(x) = 2 ^ (- E[h(x)] / c(n))
What the symbols mean
h(x)path lengthNumber of splits needed to isolate point x in one tree.
E[h(x)]average path lengthMean path length across many random isolation trees.
c(n)normalizerExpected path length for unsuccessful search in a sample of size n.
scoreanomaly scoreShorter paths produce larger anomaly scores.
Intuition: isolated points are easy to separate from the crowd.
Numeric example: if a point needs only 3 splits while most need 12, it is likely unusual.

Подходит для

  • Табличные данные (после предобработки), признаки разных масштабов.
  • Быстрый unsupervised baseline.
  • Аномалии, которые выделяются по отдельным признакам.

Ограничения

  • Score — не откалиброванная вероятность.
  • Может помечать редкие, но валидные подгруппы.
  • Порог всё равно нужно настраивать под бизнес.

One-Class SVM

One-Class SVM пытается отделить нормальные данные от начала координат в пространстве признаков (ядра). Точки вне выученной границы считаются аномалиями.

f(x) = sign(sum_i alpha_i K(x_i, x) - rho)
What the symbols mean
KkernelSimilarity function, often RBF for nonlinear boundaries.
alpha_isupport weightsLearned coefficients for support vectors.
rhooffsetBoundary threshold in feature space.
f(x)decisionPositive for inlier, negative for outlier in common implementations.
Intuition: learn the region occupied by normal data; anything outside is suspicious.
Analogy: draw a fence around known safe behavior and flag points outside the fence.

One-Class SVM хорошо работает на данных умеренного размера, но чувствителен к масштабированию признаков и параметрам ядра.

Поиск аномалий по ошибке восстановления

Autoencoder или PCA можно научить восстанавливать нормальные данные. Если объект восстанавливается плохо, он, вероятно, не следует нормальной структуре.

score(x) = ||x - decoder(encoder(x))||^2
What the symbols mean
encodercompressorMaps input into a lower-dimensional latent representation.
decoderreconstructorMaps latent representation back to input space.
x - x_hatreconstruction errorDifference between original object and reconstructed object.
||.||^2squared normLarge errors get penalized more strongly.
Intuition: if the model only learned normal patterns, abnormal patterns are hard to reconstruct.
Analogy: a stencil for normal shapes leaves obvious gaps when used on an unusual shape.

Минимальный baseline на sklearn

# What it does: trains an Isolation Forest and selects top-risk anomalies.
# Input shapes: X_train=(n_train,d), X_test=(n_test,d)
# Output shapes: scores=(n_test,), flags=(n_test,)
import numpy as np
from sklearn.ensemble import IsolationForest
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline

rng = np.random.default_rng(0)
normal = rng.normal(size=(500, 2))
outliers = rng.normal(loc=5.0, scale=0.4, size=(20, 2))
X = np.vstack([normal, outliers])

model = make_pipeline(
    StandardScaler(),
    IsolationForest(n_estimators=200, contamination=0.04, random_state=0),
)
model.fit(X)

# sklearn decision_function: lower means more abnormal, so negate it.
scores = -model.decision_function(X)
tau = np.quantile(scores, 0.96)
flags = scores >= tau

print("flagged rate:", flags.mean())
print("top scores:", np.sort(scores)[-5:])

# Gotchas:
# 1. contamination is not the true anomaly rate unless you know it.
# 2. Standardize features when distance or split behavior depends on scale.

Оценка

Если метки есть, считай anomaly score ранжированием и используй PR-AUC, recall при фиксированной доле false positives, precision@K или метрики с учётом стоимости. Если меток нет — оценивай по доле подтверждённых при разборе, объёму алертов, стабильности и ручной проверке.

precision@K = true_anomalies_in_top_K / K
What the symbols mean
Kreview capacityNumber of highest-score objects a team can inspect.
top_Khighest scoresObjects ranked as most suspicious by the model.
precisionreview yieldFraction of reviewed alerts that are real anomalies.
Intuition: if humans review only 100 alerts, the top 100 quality matters more than average score quality.
Numeric example: if 37 of top 100 alerts are real anomalies, precision@100 is 0.37.

Типичные ошибки

Ошибки моделирования
  • Интерпретировать anomaly score как откалиброванную вероятность.
  • Учить на данных, загрязнённых известными аномалиями, не проверив это.
  • Игнорировать редкие, но валидные группы.
  • Использовать порог по умолчанию без учёта цены ошибок.
Ошибки в продакшене
  • Нет бюджета алертов и процесса их разбора.
  • Нет мониторинга drift распределения score.
  • Нет обратной связи от разобранных алертов.
  • Нет анализа false positives по сегментам.

Проверь себя

Вопросы для самопроверки

  1. Чем аномалия отличается от выброса (outlier)?

    Выброс (outlier) — статистически необычная точка, которая может быть просто редкой, но нормальной. Аномалия (anomaly) — точка, отражающая реальное отклонение от ожидаемого поведения (сбой, мошенничество). На практике термины часто используют взаимозаменяемо.

  2. Как работает Isolation Forest?

    Isolation Forest строит случайные деревья, случайно разбивая пространство. Аномальные точки (редкие, далёкие) изолируются быстрее — для их выделения нужно меньше сплитов. Оценка аномальности = среднее число сплитов по лесу: чем меньше, тем аномальнее точка.

  3. Что такое One-Class SVM и когда его применяют?

    One-Class SVM обучается только на нормальных данных и строит гиперплоскость, отделяющую их от начала координат в feature space. Подходит, когда аномалий в обучающих данных нет совсем. Основной недостаток — плохо масштабируется на большие данные.

  4. Почему в системах обнаружения аномалий часто смотрят на precision@K, а не только на recall?

    Ложные срабатывания (FP) в системах обнаружения аномалий крайне дорогостоящи: они требуют ручного расследования, снижают доверие пользователей и создают операционную нагрузку. Поэтому при ограниченной ёмкости разбора часто оптимизируют precision@K — долю настоящих аномалий среди K алертов, которые команда реально успеет проверить. Но это не универсальное правило: если пропуск очень дорог (медицина, безопасность, крупный fraud), приоритет у recall, а нагрузку регулируют порогом и ёмкостью команды.

Как закрепить тему: Anomaly Detection

Блок связывает теорию с практикой: где применять идею, какие ошибки проверять и как развиваться дальше.

Когда применять

  • Используй при мониторинге систем, fraud detection, контроле качества производства.
  • Isolation Forest — хороший первый выбор без меток, LOF — для плотностного подхода.
  • Сравнивай precision@k: сколько из топ-k алертов реально аномальны.

Типичные ошибки

  • Обучать supervised-модель, когда меток аномалий почти нет — используй unsupervised.
  • Игнорировать class imbalance при оценке: accuracy почти бесполезна.
  • Не проверять threshold: многие методы дают score, порог нужно подбирать по бизнес-стоимости.

Что тюнить / проверить

  • Порог decision score — главная ручка, настраивается на labeled holdout.
  • n_estimators и contamination в Isolation Forest.
  • n_neighbors в LOF — контролирует масштаб «нормальности».
