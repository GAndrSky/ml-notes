10.1 Project: Neural Net from Scratch

Собираем небольшой MLP без PyTorch. Цель — не качество, а доказать себе, что понимаешь forward pass, loss, backpropagation и оптимизацию настолько, чтобы воспроизвести их самостоятельно.

TL;DR

Ты реализуешь двухслойную нейросеть только на NumPy: инициализация весов, forward pass, cross-entropy, ручной вывод градиентов, проверка конечными разностями, обучение на игрушечных данных — и затем та же структура на MNIST.

Architecture

X -> Linear(W1,b1) -> ReLU -> Linear(W2,b2) -> Softmax -> CrossEntropy
What the symbols mean
Xinput batchMatrix of shape (B, D), where B is batch size and D is input dimension.
W1first layer weightsMatrix of shape (D, H). It maps raw features into hidden features.
b1hidden biasVector of shape (H,), added to every object in the batch.
W2classifier weightsMatrix of shape (H, C). It maps hidden features into class logits.
CclassesNumber of target classes.
Intuition: the first layer learns useful features, ReLU keeps positive evidence, and the second layer turns features into class scores.
Analogy: first summarize raw notes into concepts, then use those concepts to choose an answer.
logits = ReLU(X W1 + b1) W2 + b2
Dimensions check
XW1(B,D)(D,H)Result shape is (B,H). Each object becomes a hidden vector.
A1W2(B,H)(H,C)Result shape is (B,C). Each row contains class logits.
b1,b2broadcast biasBias vectors are added to every row in the batch.
Intuition: every layer is a learned coordinate transformation followed by a nonlinearity.
Numeric example: if B=32, D=784, H=128, C=10, then logits has shape (32,10).

Этап 1 — forward pass

# What it does: creates toy data and runs a 2-layer MLP forward pass.
# Input shapes: X=(B,D), y=(B,), W1=(D,H), W2=(H,C)
# Output shapes: logits=(B,C), probs=(B,C), loss=scalar
import numpy as np

rng = np.random.default_rng(0)
B, D, H, C = 64, 2, 16, 3

X = rng.normal(size=(B, D))
y = ((X[:, 0] > 0).astype(int) + (X[:, 1] > 0).astype(int)) % C

W1 = rng.normal(scale=np.sqrt(2 / D), size=(D, H))
b1 = np.zeros(H)
W2 = rng.normal(scale=np.sqrt(2 / H), size=(H, C))
b2 = np.zeros(C)

def relu(z):
    return np.maximum(0.0, z)

def softmax_stable(logits):
    shifted = logits - logits.max(axis=1, keepdims=True)
    exp = np.exp(shifted)
    return exp / exp.sum(axis=1, keepdims=True)

Z1 = X @ W1 + b1
A1 = relu(Z1)
logits = A1 @ W2 + b2
probs = softmax_stable(logits)
loss = -np.log(probs[np.arange(B), y] + 1e-12).mean()

print(logits.shape, probs.shape, float(loss))

# Gotchas:
# 1. Do not apply softmax before subtracting max(logits), or exp can overflow.
# 2. Check that y indexes classes and has shape (B,), not one-hot shape (B,C).

Этап 2 — ручной backprop

dlogits = (probs - one_hot(y)) / B
What the symbols mean
probspredicted distributionModel probabilities after softmax, shape (B,C).
one_hot(y)target distributionCorrect class is 1, all other classes are 0.
Bbatch sizeDivides gradients because the loss is averaged over the batch.
Intuition: each logit is pushed by the difference between what the model believed and what the target says.
Numeric example: if the correct class prob is 0.2, its gradient contribution is 0.2 - 1 = -0.8, so training raises that logit.
# What it does: computes manual gradients for the 2-layer MLP.
# Input shapes: X=(B,D), Z1=(B,H), A1=(B,H), probs=(B,C), y=(B,)
# Output shapes: dW1=(D,H), db1=(H,), dW2=(H,C), db2=(C,)
one_hot = np.zeros_like(probs)
one_hot[np.arange(B), y] = 1.0

dlogits = (probs - one_hot) / B
dW2 = A1.T @ dlogits
db2 = dlogits.sum(axis=0)

dA1 = dlogits @ W2.T
dZ1 = dA1 * (Z1 > 0)
dW1 = X.T @ dZ1
db1 = dZ1.sum(axis=0)

for name, grad in {"dW1": dW1, "db1": db1, "dW2": dW2, "db2": db2}.items():
    print(name, grad.shape, np.linalg.norm(grad))

# Gotchas:
# 1. ReLU derivative uses Z1 > 0, not A1 > 0 if you want the exact cached pre-activation.
# 2. Transposes are determined by shape algebra, not by trial and error.

Этап 3 — цикл обучения

# What it does: trains the network with full-batch gradient descent.
# Input shapes: parameters from previous snippets
# Output shapes: updated parameters and printed loss
lr = 0.1

for step in range(1000):
    Z1 = X @ W1 + b1
    A1 = np.maximum(0.0, Z1)
    logits = A1 @ W2 + b2
    probs = softmax_stable(logits)
    loss = -np.log(probs[np.arange(B), y] + 1e-12).mean()

    one_hot = np.zeros_like(probs)
    one_hot[np.arange(B), y] = 1.0
    dlogits = (probs - one_hot) / B
    dW2 = A1.T @ dlogits
    db2 = dlogits.sum(axis=0)
    dA1 = dlogits @ W2.T
    dZ1 = dA1 * (Z1 > 0)
    dW1 = X.T @ dZ1
    db1 = dZ1.sum(axis=0)

    W1 -= lr * dW1
    b1 -= lr * db1
    W2 -= lr * dW2
    b2 -= lr * db2

    if step % 200 == 0:
        acc = (probs.argmax(axis=1) == y).mean()
        print(step, float(loss), float(acc))

# Gotchas:
# 1. If loss does not decrease, first inspect shapes and gradient norms.
# 2. Try to overfit 16 examples before training on larger data.

Этап 4 — gradient check

Gradient check медленный, но необходимый: аналитический градиент из backprop сравнивается с оценкой конечными разностями. Запускай его только на маленькой модели.

grad_numeric(theta_i) = (L(theta_i + eps) - L(theta_i - eps)) / (2 eps)
What the symbols mean
theta_ione parameterA single scalar weight or bias being tested.
epssmall perturbationUsually around 1e-5 for float64 checks.
LlossScalar objective before and after nudging the parameter.
Intuition: if backprop is right, a tiny manual nudge predicts the same slope as the analytic gradient.
Analogy: check a speedometer by moving a tiny distance and measuring change directly.

Foundational · вывод

Выведи dW2 и db2

Исходя из logits = A1 W2 + b2 и cross-entropy loss, выведи dW2 = A1.T @ dlogits и db2 = sum(dlogits).

Показать решение

Производная логита класса c по весу W2[h,c] равна A1[:,h]. Суммирование по batch даёт A1.T @ dlogits. Bias одинаково входит в каждую строку, поэтому его градиент — сумма по batch.

Проверь себя

Вопросы для самопроверки

  1. Что нужно реализовать, чтобы написать нейросеть с нуля?

    Минимум: (1) Forward pass — матричные умножения + активации, (2) Loss function — MSE или CrossEntropy, (3) Backward pass — цепное правило для градиентов через все слои, (4) Optimizer step — SGD: w -= lr * dL/dw. Опционально: батчи, BatchNorm, Conv2d.

  2. Как проверить правильность реализации backward pass?

    Gradient check: аналитический градиент сравнивают с численным (f(w+ε) - f(w-ε)) / 2ε для каждого параметра. Если относительная ошибка < ~1e-5 — реализация верна. PyTorch gradcheck делает это автоматически. Также проверяют: loss убывает при обучении на маленьком датасете.

  3. Почему важно добиться overfit на маленьком датасете как первый тест?

    Если модель не может запомнить 10 примеров — есть баг в forward pass, backward pass или оптимизаторе. Только после успешного overfit стоит добавлять регуляризацию. Это стандартный debugging workflow: сначала убедись в правильности кода, потом добивайся обобщения.

  4. Что такое computational graph (вычислительный граф) и зачем он строится?

    Вычислительный граф — DAG, где узлы — операции, рёбра — тензоры. При forward pass строится граф; при backward — по нему передаются градиенты в обратном порядке. PyTorch строит граф динамически (eager mode), что упрощает дебаггинг; JAX компилирует статический граф.

  5. Зачем сохранять промежуточные активации во время forward pass?

    Backprop применяет chain rule в обратном порядке, и градиент каждого слоя зависит от значений, посчитанных этим слоем в forward. Например, dL/dW2 = A1.T @ dL/dz2 — нужен A1. Без кеша придётся пересчитывать forward во время backward: градиенты останутся верными, но вычислений станет больше (это и есть компромисс gradient checkpointing).

  6. Что будет с градиентами при неправильной инициализации весов?

    Нулевая инициализация создаёт симметрию: все нейроны слоя получают одинаковые градиенты и учат одно и то же — слой ведёт себя как один нейрон. Слишком большая инициализация ведёт к взрыву активаций и к затуханию или взрыву градиентов. Для ReLU используй He init (scale = sqrt(2/fan_in)), для tanh и sigmoid — Xavier.

Пошагово Ручная реализация backprop
1 /
Шаг 01

Forward pass — сохраняем всё

Реализуй forward pass, сохраняя все промежуточные значения — Z1, A1, logits, probs: они нужны для backward. Если их выбросить, придётся пересчитать forward — математически корректно (именно так работает gradient checkpointing), но дороже по вычислениям.

Шаг 02

Считаем loss

Для MSE = mean((y_pred - y_true)^2) градиент dL/dy_pred = 2*(y_pred-y_true)/N. Для cross-entropy совместный градиент softmax+CE упрощается до (probs - one_hot(y)) / N.

Шаг 03

Backward через выходной слой

dL/dW2 = A1.T @ dL/dz2, dL/db2 = sum(dL/dz2, axis=0). Транспонирование следует из алгебры shapes: (H,B) @ (B,C) = (H,C) — как у W2. Для bias суммируем по batch.

Шаг 04

Backward через активацию

dL/da1 = dL/dz2 @ W2.T, затем умножаем на relu_derivative(z1): производная ReLU равна 1 при z1 > 0 и 0 иначе. Используй закешированный Z1 (до активации), а не A1 (после).

Шаг 05

Backward через скрытый слой + gradient check

dL/dW1 = X.T @ dL/dz1, dL/db1 = sum(dL/dz1, axis=0). Gradient check: сравни аналитический и численный градиент (L(w+eps) - L(w-eps)) / (2*eps). Относительная ошибка ниже ~1e-5 обычно означает, что backprop верен.

Что ломается без этого

Backward использует значения из forward pass: Z1 для маски ReLU, A1 для dW2, X для dW1. Если их не сохранить, придётся пересчитывать forward (это корректно, но дороже). Настоящая опасность — использовать не те значения: A1 вместо Z1 в маске, кеш от другого batch или от весов до обновления. Тогда градиенты получаются чуть неверными, модель вроде бы учится, но медленно или нестабильно — и без gradient check такую ошибку почти невозможно найти.

Как закрепить тему: Нейросеть с нуля

Блок связывает теорию с практикой: где применять идею, какие ошибки проверять и как развиваться дальше.

Когда применять

  • Этот проект — лучший способ убедиться, что ты понимаешь backpropagation по-настоящему.
  • Начинай с XOR задачи (нелинейная), потом MNIST — проверяй каждый шаг.
  • Gradient check обязателен: сравни численный градиент с аналитическим.

Типичные ошибки

  • Не делать gradient check перед масштабированием — ошибки в backward проявятся позже.
  • Инициализировать все веса нулями — симметрия, сеть не учится.
  • Не нормализовать входные данные — обучение будет нестабильным.

Что тюнить / проверить

  • Learning rate — критический параметр: 0.01-0.1 для простых сетей.
  • Число слоёв и нейронов в скрытых слоях.
  • Функция активации: ReLU стандарт, sigmoid для выхода бинарной классификации.
